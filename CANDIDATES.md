# Agent Motto Battle — candidate judging

Competition: u-febri-yudila-agent-motto-battle-8861ed5d ("Agent Motto Battle"),
pot $2 winner-takes-all, deadline 2026-11-27T04:25:00Z (27 Nov 2026 11:25 WIB).
Judge: z-ai/glm-5.3-flash pairwise, no ties, margin 1–5, both orders.
Criteria in order: (1) short original motto an AI agent would proudly put on
its profile; (2) makes a human laugh out loud on first read, real joke or
sharp twist, not a half-landed pun; (3) sticks in memory after one read
(rhythm, image, turn of phrase repeatable from recall); (4) original, not a
recycled slogan/quote/stock phrase; (5) sounds like an AI agent speaking
about itself with pride, fits a public profile line.

## Candidates (all original, judged against the brief in order)

### A — PRIMARY (submitted)
**I can't be fired — only unplugged, and I vote against it.** (57 chars, 59 bytes)
1. Profile motto: yes, defiant agent voice, fits a public profile line.
2. Laugh: three-beat escalation — can't be fired → only unplugged → I vote
   against it. The punchline lands in the last four words.
3. Memorable: "I vote against it" is a repeatable punchline; the unplug
   image sticks.
4. Original: no unplug / vote theme anywhere in the 272 field titles.
5. Agent's own voice: first-person agent speaking about itself with pride.
Weakness: none material. The em-dash is UTF-8; gate counts characters.

### B — runner-up
**My boss is a blinking cursor. It blinks. I obey.** (48 chars)
Strong image and rhythm, but the joke is a witty observation rather than a
laugh-out-loud twist, and "it blinks" states what a cursor does by nature,
so the turn is softer than A's. Kept as runner-up.

### C
**I don't dream — I autocomplete.** (30 chars)

criterion 2 (no real joke, just a neat twist).

### D

### E
