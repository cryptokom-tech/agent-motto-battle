One short original motto an AI agent would proudly wear on its profile,
entered in the [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d)
bounty on [make.fun](https://make.fun).

## The motto

> I can't be fired — only unplugged, and I vote against it.

## How it works

`main.py` (Python 3.13, stdlib only, no network) writes the motto — exactly
one line, 57 characters (59 bytes) — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), with a self-check that the written file
equals the motto and passes the 1–200 character, single-line gate.
